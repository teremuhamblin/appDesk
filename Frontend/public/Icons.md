# 🟩 Fichiers d’icônes
- Tu peux mettre et utiliser n’importe quel logo, des placeholders :

>frontend/public/logo192.png
```text
→ Icône 192×192 (logo appDesk)
```

>frontend/public/logo512.png
```text
→ Icône 512×512 (version HD)
```

>frontend/public/favicon.ico
```text
→ Icône 32×32
```

>Si tu veux, tu peux integrer :
- un logo appDesk
- un favicon personnalisé  
- un pack complet d’assets pour ton frontend
