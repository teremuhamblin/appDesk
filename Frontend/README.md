# 🎨 appDesk
>Frontend

Le frontend d’appDesk fournit l’interface utilisateur : gestion des tickets,
visualisation du parc, tableaux de bord, base de connaissances et administration.

### Fonctionnalités
- Interface moderne (React ou Vue 3)
- Tableau de bord dynamique
- Formulaires de création/gestion des tickets
- Vue inventaire (machines, logiciels, contrats)
- Authentification et gestion de session
- Intégration complète avec l’API backend

### Stack technique
- React + Vite + TailwindCSS  
  *(ou Vue 3 + Vite selon configuration du projet)*  
- Axios pour les appels API
- Docker pour le déploiement

### Démarrage

```bash
# Installer les dépendances
npm install

# Lancer le serveur de dev
npm run dev
```

### Build
```bash
npm run build
```
