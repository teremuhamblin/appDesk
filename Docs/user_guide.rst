==========================
Guide Utilisateur appDesk
==========================

Introduction
============

Ce guide explique comment utiliser appDesk au quotidien : création de tickets,
consultation du parc, recherche, notifications et base de connaissances.

Connexion
=========

L’utilisateur se connecte via l’interface frontend.

Création d’un ticket
====================

1. Cliquer sur "Nouveau ticket".
2. Saisir le titre, la description, la priorité.
3. Envoyer.

Consultation des tickets
========================

- Filtrer par statut
- Filtrer par priorité
- Rechercher par mot-clé

Inventaire des actifs
=====================

L’utilisateur peut :

- consulter les machines
- vérifier les logiciels installés
- voir les contrats associés

Base de connaissances
=====================

- Rechercher un article
- Lire les procédures
- Accéder aux FAQ

Notifications
=============

Les utilisateurs reçoivent des notifications :

- création de ticket
- assignation
- changement de statut
