=============================
Manuel Opérateur / Technicien
=============================

Introduction
============

Ce guide est destiné aux techniciens utilisant appDesk pour gérer les tickets,
les actifs et les opérations quotidiennes.

Gestion des tickets
===================

- assignation
- changement de statut
- ajout de commentaires
- clôture

Actions rapides
===============

- escalade
- transfert
- ajout de pièces jointes
- historique complet

Gestion des actifs
==================

Le technicien peut :

- ajouter un actif
- modifier un actif
- associer un utilisateur
- consulter les logs

Outils internes
===============

- monitoring
- logs système
- tâches Celery
